Balthazar — стартап, создающий ИИ-платформу для управления экспериментами в научно-исследовательских лабораториях наукоёмких отраслей (полупроводники, фотоника и т. п.).

<p class="tech-stack"><strong>Стек:</strong> React, TypeScript, Effector, Feature-Sliced Design, TanStack Query, TanStack Virtual, TanStack Router, React Hook Form, i18next, shadcn/ui, Tailwind CSS, AG Grid, FINOS Perspective, Monaco Editor, Tiptap, WebSockets, Keycloak, Playwright, Vitest</p>

- С нуля создал frontend платформы и вывел его в production. Координировал работу двух full-stack разработчиков над клиентской частью, оставаясь основным разработчиком frontend: принимал архитектурные решения, оценивал задачи, проводил code review и согласовывал API-контракты с backend-командой.
- Разработал ленты и карточки сущностей платформы (эксперименты, устройства и др.), в которых текстовые данные и графики, созданные пользователем, обновляются в реальном времени. Графики отрисовываются на Canvas, а в лентах с бесконечной прокруткой обновляется только видимая часть, что сохраняет производительность.
- Сделал формы добавления и редактирования сущностей, настройки связей между ними и управления правами доступа. Формы построены на React Hook Form с валидацией по Zod-схемам, сгенерированным из OpenAPI-спецификации.
- Построил сводную аналитику данных платформы на AG Grid и FINOS Perspective (WASM): сложносоставные таблицы и графики разных типов с фильтрацией, сортировкой, поиском, выгрузкой данных и редактированием сущностей и связей между ними прямо в таблице.
- Реализовал работу с Python-скриптами: редактор кода на Monaco Editor с автодополнением, редактируемое дерево файлов подключённого Git-репозитория и интерфейсы для подключения сущностей к скрипту, позволяющие использовать их параметры в коде. Логи выполнения обновляются в реальном времени и доступны для выгрузки, а курсорная пагинация и виртуализация на TanStack Virtual сохраняют отзывчивость при любом размере лога.
- Добавил инструменты совместной работы: документацию в Markdown с историей изменений и разграничением прав, ветки комментариев с ответами и вложениями, обновляющиеся в реальном времени, а также чат с AI-ассистентом.
- Выстроил работу с серверными данными на TanStack Query, а клиентскую бизнес-логику — на Effector; интегрировал авторизацию через Keycloak. OpenAPI-спецификацию превратил в единый источник правды для контракта с backend: из неё генерируются типизированный fetch-клиент, хуки TanStack Query, TypeScript-типы, Zod-схемы и тестовые данные.
- Собрал кастомный UI-kit на основе shadcn/ui с поддержкой доступности (a11y), сделал все экраны адаптивными от планшета до десктопа и внедрил интернационализацию. Быструю загрузку на слабых устройствах и при медленном соединении обеспечил за счёт code splitting по роутам на TanStack Router и ленивой загрузки тяжёлых модулей (React.lazy, Suspense).
- Настроил тестирование, мониторинг и правила разработки: e2e-тесты на Playwright, unit-тесты на Vitest и единое окружение через Docker, отслеживание ошибок в production через Sentry, архитектурные правила для AI-агентов, используемых в разработке.
