Detsky Mir is Russia's largest children's goods retailer. Worked on its marketplace supplier portal, covering product management, supply management, financial settlements, and electronic document management with document signing.

<p class="tech-stack"><strong>Stack:</strong> TypeScript, React, React Router, Redux Toolkit, RTK Query, MUI, Styled Components, Storybook, Koa.js, Cypress, Jest, React Testing Library, Webpack, Unleash, GitLab CI/CD</p>

- Developed and maintained a React and Redux Toolkit SPA as part of a team of 10 frontend developers; helped onboard new team members.
- Developed portal sections for creating and editing product listings with variants and sizes, managing prices, supplies and inventory, and providing analytical reports for suppliers.
- Led the migration of the state management layer from Redux and Redux Thunk to Redux Toolkit and RTK Query, eliminating boilerplate reducer code and manual data-fetching logic.
- Extended the internal MUI-based component library and its Storybook catalog: developed complex table and form components and customized the theme to match the design system, enabling new portal sections to be assembled from reusable components.
- Developed a Koa.js Backend-for-Frontend (BFF) service that aggregated data from multiple backend services and proxied authentication, reducing the number of client requests and simplifying frontend logic.
- Covered key user workflows with Cypress end-to-end tests and tested components using Jest and React Testing Library. Configured CI/CD in GitLab, refactored the Webpack configuration, and managed the implementation of feature flags with Unleash.
